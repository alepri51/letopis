# Все нюансы

Ловушки и неочевидные правила letopis одним списком — из карточек атласа, раздела «Ограничения» README, CHANGELOG и того, что нашли прогоны примеров. У каждого — глава, где он показан исполняемым примером на живых данных.

Страница собирается скриптом `guide/scripts/gen-nuances.ts` из `guide/coverage/nuances.ts`; что у каждого нюанса есть пример, проверяет `npm run coverage`.

| Нюанс | Где показан |

| delete() без { confirm: true } ничего не удаляет — возвращает превью: что удалится и с каким действием ($action). | [1. Что такое letopis](../basics/what-is) |
| Описание класса — тоже объект: строка класса Class в entity со своей историей в log. | [1. Что такое letopis](../basics/what-is) |

| Повторный up() безопасен: накатывает ту же ревизию, данные не трогает, ключ сервиса снова не выдаёт. | [2. Установка](../install/) |
| Ключ сервиса up() выдаёт только при первой установке или когда не осталось ни одного действующего ключа API. | [2. Установка](../install/) |

| history: false — нет журнала: ни версий, ни среза на дату, ни восстановления, ни событий подписки. | [3. Модели](../models/) |
| update сливает патч внутри базы: вложенные объекты — рекурсивно, массивы и скаляры заменяются. | [4. Запись](../write/) |
