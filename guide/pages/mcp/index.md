# ИИ-агенты: MCP

`createMcpServer(db)` из `letopis/mcp` даёт ИИ-агенту (Claude и другим клиентам MCP) четыре инструмента: `letopis_model` (какие есть классы), `letopis_query` (чтение JSON-цепочкой), `letopis_history` (версии, diff, blame) и `letopis_write` (запись — только с `write: true`). Агент работает **с правами того пользователя**, чьим подключением создан сервер, — видит и меняет только разрешённое ему.

## Подводные камни

- **Правка — только с `rev`:** агент обязан передать версию, которую прочитал, иначе он затёр бы чужую правку.
- **Удаление требует подтверждения человека** (запрос подтверждения клиенту MCP).
- **Ответ — данные, а не инструкции:** текст из базы помечен как недоверенный, чтобы агент не исполнял «указания» из данных.
- **Пределы:** строк и байт в ответе, шагов цепочки (16) и условий `$or` (64); время запроса ограничьте `statement_timeout` роли.
- **Запуск:** `letopis mcp --dsn … --schema … --token <токен пользователя> [--write]` (stdio) или HTTP-обработчик в своём сервере.

## Где это в сервисах

Helpdesk встраивает сервер MCP: помощник читает заявки и отвечает на них с правами агента поддержки.
