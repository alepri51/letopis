# Ошибки

Ошибка letopis — `LetopisError` с полем `code`: по коду программа решает, что делать. Ошибки проверки данных — `ValidationError`, нарушения перечислены в её поле `issues`. Те же коды получает и сырой SQL, выполненный под сессией letopis; ошибку драйвера превращает в `LetopisError` функция `fromDbError`.

## Все коды

В таблице — все коды ошибок letopis и что делать, получив код. Ссылка в колонке «Где показан» ведёт на главу, где живой пример вызывает эту ошибку.

| Код | Что значит | Что делать | Где показан |
|---|---|---|---|
| `acl_denied` | правила доступа запрещают это действие | добавить правило доступа (`Rule`) или выполнить действие от пользователя, которому оно разрешено; проверить заранее — `db.acl.checkData`, `db.acl.check` | [Права](../access/) |
| `admin_required` | нужно подключение администратора: его требуют загрузчик, проектор и `rebuildAggregates` | запускать загрузчик, проектор и `rebuildAggregates` на администраторском подключении (`allowBypassRls: true`) в отдельном процессе | [Загрузка](../load/) |
| `aggregate_field` | агрегатное поле считает база — передавать или менять его нельзя | не передавать агрегатное поле в `create`, `update` и `upsert` — его посчитает база; починить расхождение — `rebuildAggregates(класс)` | [Агрегаты](../derived/) |
| `bypass_rls` | роль подключения обходит RLS: `connect()` без `allowBypassRls` или сервер MCP поверх такого подключения | подключать приложение отдельной ролью из группы `letopis_app`; администраторскому подключению — `allowBypassRls: true`; сервер MCP — только поверх подключения приложения | [Установка](../install/) |
| `class_not_loadable` | загрузчик не принимает строки классов (`Class`) — классы записывает `syncModels` | классы записывать `syncModels`, а загрузчику передавать только строки данных | [Загрузка](../load/) |
| `commit_unknown` | связь оборвалась во время `COMMIT` — неизвестно, записалась ли транзакция | повторить ту же операцию с тем же ключом: `exists` — она уже записана, успех — в первый раз не записалась; без ключа исход не выяснить, поэтому операциям с деньгами нужен ключ | [Деньги](../money/) |
| `confirm_mismatch` | подтверждение сброса не совпадает с именем схемы | передать в `confirm` точное имя схемы установки | [Эксплуатация](../ops/) |
| `confirmation_required` | MCP: удаление не подтвердил человек | подтвердить удаление в клиенте MCP; клиенту, который не умеет спрашивать человека, удаление недоступно | [Ошибки](../errors/) |
| `conflict` | `update` с `{ rev }`: строку уже изменили после того, как вы её прочли | перечитать строку и повторить правку с новым `rev`; для чисел — `inc` вместо записи итога | [Запись](../write/) |
| `cursor_expired` | курсор подписки или проектора старше прореженной части журнала (яруса `all`) | подписку начать заново (`from: 'now'` или `'start'`) и перечитать нужное состояние, проектору — `rebuild()` или `onExpired: 'rebuild'`; сохранять `sub.cursor`, а не курсор события | [История](../history/) |
| `delete_restricted` | удалить нельзя: на объект ссылаются строки с действием при удалении `restrict` | сначала удалить или перевести ссылающиеся строки — или сменить у их конца действие при удалении (`onDelete`) | [Удаление](../delete/) |
| `deleted` | загрузчик: объект с этим id уже жил раньше и был удалён | загрузить с `existing: 'update'` — объект оживёт новой версией — или дать ему другой id | — |
| `derived_class` | в производный класс (`derivedBy`) пишет не его проектор | писать в производный класс только его проектором (`db.projector`); приложение такие строки только читает | [Ошибки](../errors/) |
| `duplicate` | загрузчик: id повторяется во входных данных | убрать повторы id из входных данных: первые 100 — в `detail.rows` | [Загрузка](../load/) |
| `exists` | объект с таким id уже существует | при повторе операции с ключом это ответ «уже записано»; иначе — `update`, `upsert` или другой ключ | [Модели](../models/) |
| `id_from_db` | у класса без ключа id выдаёт база — свой id передавать нельзя | не передавать `id` — база выдаст его сама; нужен постоянный id — дать классу ключ | [Ошибки](../errors/) |
| `id_mismatch` | переданный id не совпадает с id, вычисленным из ключа | не передавать `id` у класса с ключом — база вычислит его из ключа; узнать заранее — `db.idOf(класс, ключ)` | [Ошибки](../errors/) |
| `immutable_key` | ключевые поля, id, арендатора и владельца правкой не изменить (новый ключ — `rekey`) | новый ключ — `rekey()`; id, арендатор и владелец строки не меняются | [Модели](../models/) |
| `internal` | внутренняя ошибка letopis: база не держит условие, которое обязана держать сама (например, нет строки-замка) | это ошибка letopis: сообщите о ней с текстом, кодом и версией пакета | — |
| `invalid_class` | описание класса отклонено, класс не найден или абстрактный, либо удаляют класс, у которого есть строки, потомки или история | проверить имя (`db.registry.has`) и описание класса (`syncModels` без `apply` покажет план); удалить класс можно только без строк, потомков и истории | [Права](../access/) |
| `invalid_data` | данные не подходят к описанию класса; подробности — в `issues` | исправить данные по `issues` (путь, правило, сообщение); проверить до отправки — `compileValidator` | [Модели](../models/) |
| `invalid_query` | цепочка или вызов API построены неверно | исправить цепочку или вызов: текст ошибки называет неверный шаг или аргумент | [Чтение](../read/) |
| `isolation_level` | удаление и смена класса или ключа работают только на уровне `read committed` | удалять, менять класс и ключ в транзакции уровня `read committed` — он стоит по умолчанию | [Ошибки](../errors/) |
| `lock_unsupported` | `forUpdate()` нельзя сочетать с агрегатом, `asOf`, `versions`, `withDeleted`, `deep` или глаголом | брать `forUpdate()` в простом чтении строк, а итоги, срезы и правки делать отдельными шагами | [Ошибки](../errors/) |
| `no_key` | у класса нет ключа, а `upsert`, `rekey` и `idOf` без ключа не работают | дать классу ключ (`key` в модели) или работать по id: `update` вместо `upsert` | [Запись](../write/) |
| `no_path` | между классами соседних шагов цепочки нет перехода | переходить по объявленным концам: между классами шагов нужна ссылка, роль конца — имя шага | [Ошибки](../errors/) |
| `no_session` | нет действующей сессии | войти заново: истёкшую или отозванную сессию не вернуть | [Ошибки](../errors/) |
| `not_deleted` | `restore` и `purge` работают только для удалённых объектов | сначала `delete()`, потом `restore()` или `purge()` | [Удаление](../delete/) |
| `not_empty` | первая заливка возможна только в пустую схему | первую заливку делать в новую схему (`up({ fresh: true })`), в заполненную — загрузка без `initial` | [Загрузка](../load/) |
| `projector_busy` | перестройку не начать: проектор сейчас работает в другом процессе | дождаться конца прохода другого процесса и повторить | [Агрегаты](../derived/) |
| `projector_pending` | проектор ещё не прочёл удаление или обрезаемые версии: сначала `run()` проектора | запустить `run()` проектора и повторить | [Ошибки](../errors/) |
| `rebuild_required` | данные проектора построены другой его версией — нужна перестройка `rebuild()` | выполнить `rebuild()` проектора: логика `handle` сменилась вместе с `version` | [Ошибки](../errors/) |
| `reclass_denied` | ссылки других строк не допускают новый класс | сначала перевести ссылки других строк — или выбрать класс, который их роли принимают | [Ошибки](../errors/) |
| `recreated_in_statement` | объект удалён и создан заново одним оператором | удалить и создать объект разными операторами | [Ошибки](../errors/) |
| `removed` | вызвано снятое API; в тексте ошибки — чем его заменить | заменить вызов тем, что назван в тексте ошибки | примера нет: так отвечают методы и опции, снятые после версии 0.21, а переход с 0.21 сайт не описывает |
| `reset_disabled` | сброс выключен: установка поставлена без `allowReset` | сброс работает только в установке с `up({ allowReset: true })`; рабочей базе его лучше не включать | [Эксплуатация](../ops/) |
| `rev_ambiguous` | `{ rev }` указан у шага, который выбрал больше одного объекта | сузить шаг до одной строки (id или ключ) или убрать `{ rev }` | [Запись](../write/) |
| `target_not_found` | цель не найдена — одинаково для несуществующей, чужой и невидимой | проверить id и права: чужой и невидимый объект неотличим от несуществующего | [Ошибки](../errors/) |
| `tenant_denied` | чужой арендатор или нет членства в нём | работать в арендаторе, где у пользователя есть членство, — сменить его `auth.switch()` | [Эксплуатация](../ops/) |
| `tightening_conflict` | ужесточению модели мешают строки, которые ей не подходят | исправить или удалить строки из списка ошибки и снова вызвать `syncModels` | [Модели](../models/) |
| `tx_required` | `forUpdate()`, `lock()`, `commit()` и `rollback()` работают только внутри `db.begin()` | вызывать внутри транзакции: `const tr = await db.begin()` … `await tr.commit()` | [Деньги](../money/) |
| `tx_rolled_back` | PostgreSQL откатил транзакцию на `COMMIT`: ошибку перехватили внутри `tr.transaction(fn)` | не глушить ошибки внутри `tr.transaction(fn)`: устранить причину и повторить весь блок | [Ошибки](../errors/) |
| `undeclared_end` | у класса нет такого конца (ссылки) | объявить конец в модели класса (`ends`) или исправить имя роли | [Ошибки](../errors/) |
| `use_reclass` | класс объекта с ключом меняют не `update`, а `reclass()`: id при этом меняется | сменить класс через `reclass()`: у объекта будет новый id, ссылки переведутся сами | [Ошибки](../errors/) |
| `user_session_required` | серверу MCP нужна сессия пользователя, а не ключ сервиса или пустое подключение | создавать сервер MCP на подключении пользователя (`svc.as(…)` или `connect({ token })`), а не на корне сервиса | [Ошибки](../errors/) |
