# Загрузка

Загрузчик пишет много строк любых классов быстрее цепочек: проверки — в коде, строки — через COPY. Работает только на администраторском подключении.

## Загрузчик

### db.load() {#db-load}

```ts
load(input: LoadInput, opts?: LoadOptions): Promise<LoadReport>
```

Загрузчик: строки любых классов — проверки в коде, COPY от роли владельца, один запрос по целям вне загрузки. Только на администраторском подключении (иначе admin_required).

Строки проверяет сама библиотека — тем же описанием класса, что и база, — и пишет их командой `COPY` (быстрая массовая вставка PostgreSQL) от имени роли-владельца схемы. Ссылки на объекты вне загрузки сверяются одним запросом в конце. Порядок строк и классов не важен, ссылки по кругу допустимы. Загрузка идёт одной транзакцией: ошибка в любой строке отменяет всё (с `commitEvery` — только текущую порцию). Код ошибки — код первой проблемы, `detail.rows` — первые 100 нарушений (`line` — номер строки входа с 1, `code`, `message`, `id`, `class`, `issues`), `detail.total` — сколько нарушений найдено. Поток строк читается в память целиком до начала записи. Подписки и кэши других процессов узнают о строках после фиксации.

**Параметры**

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `input` | `LoadInput` | обязательный | Строки: объект «класс → строки» (`{ Shop: [...], Product: [...] }`), массив строк с полем `$class` или поток строк (итератор, в том числе асинхронный). Строка — поля и роли концов на верхнем уровне; служебные ключи: `$class` — класс, `$ext` — внешний ключ, то есть id строки в другой системе (у класса без ключа: повторная загрузка того же файла даёт те же id), `$tags` — теги, `$owner` — владелец. Ссылка на цель — её id, ключ `{ $key: [...] }` или внешний ключ `{ $ext: '…' }`; если конец принимает несколько классов, добавьте в такую ссылку `$class` цели. |
| `opts` | `LoadOptions` | `{}` | Опции загрузки — таблица ниже. |

**Опции `LoadOptions`**

| Опция | Тип | По умолчанию | Описание |
|---|---|---|---|
| <span id="load-duplicates"></span>`duplicates` | `'error' \| 'first' \| 'last'` | `'error'` | Повтор id в загрузке: отменить загрузку (по умолчанию), оставить первую или последнюю строку. Повтор id — две строки входа, которые дают один объект: одинаковый ключ или `$ext`. Отброшенные строки считаются в `duplicates` отчёта. В режиме истории (`withHistory`) опция не действует: строки одного id — его версии.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-existing"></span>`existing` | `'error' \| 'skip' \| 'update'` | `'error'` | Объект уже есть в базе: отменить (по умолчанию), пропустить или записать новую версию. С `'error'` загрузка отменяется с кодом `exists` (объект есть) или `deleted` (объект с этим id жил раньше и удалён). `'skip'` пропускает и удалённые раньше объекты — не создаёт их заново. `'update'` пишет новую версию, только если содержимое отличается (неизменённые считаются в `skipped`), а удалённые создаёт заново с прежним id.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-batch"></span>`batch` | `number` | `10000` | Строк в пачке COPY (по умолчанию 10 000).<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-commitevery"></span>`commitEvery` | `number` | нет — вся загрузка одной транзакцией | Фиксировать порциями примерно по N строк (порция — классы в порядке зависимостей, цикл — целиком). Ошибка отменяет только текущую порцию: зафиксированные раньше остаются, и повтор с `existing: 'skip'` допишет остальное. Порции идут по классам: сначала те, на которые ссылаются, а классы, которые ссылаются друг на друга по кругу, и класс со ссылками на самого себя целиком попадают в одну порцию. Несовместима с `initial`.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-withhistory"></span>`withHistory` | `boolean` | `false` | Режим истории: строки — версии с $rev, $at и $op; пишутся волнами. Каждая строка — одна версия объекта: `$rev` — номер версии (у каждого объекта подряд от 1), `$at` — время версии, `$op` — вид операции (по умолчанию `create` у первой версии и `update` у остальных). Текущим состоянием становится последняя версия, а если она — `delete`, объект записывается удалённым. Автор версий — System. «Волнами» — по номерам версий: сначала первые версии всех объектов, затем вторые и так далее. Несовместим с `as` и `existing: 'update'`.<br>Примеры: [Хранение истории по ярусам: maintain, trimHistory, cursor_expired](../history/#хранение-по-ярусам) |
| <span id="load-verify"></span>`verify` | `boolean` | `false` | В конце перепроверить загруженные строки проверкой базы. База ещё раз проверяет данные загруженных строк по описанию класса и цели их концов. Нарушение отменяет загрузку; ошибка называет не больше 100 таких строк.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-class"></span>`class` | `string` | нет | Класс строк без $class (CLI --class). Нужна, когда во входе массив или поток строк без `$class`. Строки со своим `$class` её не учитывают, а у входа «класс → строки» класс задаёт ключ объекта.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-tenant"></span>`tenant` | `string` | арендатор сессии; с `as` — собственный арендатор пользователя | Арендатор строк (по умолчанию — арендатор сессии). Арендатор должен существовать и быть включён, иначе `tenant_denied`.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-agent"></span>`agent` | `string` | `'letopis load'` | Агент версий (по умолчанию «letopis load»). Агент — исполнитель записи: журнал хранит его в поле `agent` рядом с автором версии.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-as"></span>`as` | `string` | нет — от имени администратора, автор версий System | Загрузка от имени пользователя: автор версий — он; арендатор (по умолчанию — собственный аккаунта) доступен ему; право WRITE на каждый класс и условия ACL на новые (и в existing: 'update' — прежние) значения строк; цели ссылок ему видны; владелец — по ownerDefault. Значение — id аккаунта пользователя. Загрузчик проверяет то же, что база при обычной записи от его имени; «доступен» — это собственный арендатор пользователя или арендатор, где у него есть членство. `$owner` в строках задавать нельзя. Так процесс загрузки принимает файлы, присланные пользователями. Несовместим с `withHistory` и `initial`.<br>Примеры: [Массовая загрузка db.load: входные данные, ссылки по ключу, повторы, уже существующие объекты](../load/#пример-вход-ссылки-по-ключу-повторы-уже-существующее) |
| <span id="load-initial"></span>`initial` | `boolean` | `false` | Первая заливка: только в пустую схему (кроме строк системных классов — иначе not_empty), одной транзакцией; на время загрузки схема закрыта, индексы и триггеры сняты и перестраиваются в конце. Без commitEvery, existing (кроме 'error') и { as }. «Закрыта» — другие подключения не читают и не пишут таблицы схемы до конца заливки. Пустая — значит, кроме описаний классов, аккаунтов, членств, ресурсов и правил (и записей сброса), в схеме ничего нет. Ошибка любой строки откатывает всю заливку, и индексы с триггерами возвращаются на место.<br>Примеры: [Первая заливка: db.load(…, { initial: true })](../load/#первая-заливка) |

**Возвращает:** `Promise<LoadReport>` ([LoadReport](./types#type-loadreport)) — Отчёт: `rows` — строк во входе; `loaded` — записано объектов: новых и созданных заново после удаления; `updated` — новых версий существующих объектов (`existing: 'update'`); `skipped` — пропущено существующих и неизменённых; `duplicates` — пропущено повторов id; `byClass` — записано по классам; `external` — сколько целей вне загрузки сверено запросом в конце; `portions` — зафиксировано порций; `ms` — время загрузки в миллисекундах.

**Ошибки** ([все коды](../errors/)):

- `admin_required` — подключение не администраторское: нужны `connect({ allowBypassRls: true })` и роль, которая может стать владельцем схемы.
- `invalid_query` — вызов внутри `db.begin()`: загрузка идёт своими транзакциями.
- `invalid_data` — неверные или несовместимые опции: `as` — не id аккаунта; `as` вместе с `withHistory` или `initial`; `withHistory` с `existing: 'update'`; `initial` с `commitEvery` или с `existing`, отличным от `'error'`. А также: неверный вход; нет арендатора (у сессии его нет и не задан `tenant`); строка не проходит описание класса или неверны её концы, `$tags`, `$owner`, `$ext`, части ключа; в режиме истории `$rev` идут не подряд от 1 или нет `$at`.
- `invalid_class` — класс строки не найден, у строки нет `$class` или класс абстрактный.
- `class_not_loadable` — во входе строки `Class`: описания классов записывает `syncModels`.
- `derived_class` — строка производного класса (`derivedBy`) или ссылка на такую строку: строки производных классов пишет только проектор.
- `duplicate` — id повторяется во входе (при `duplicates: 'error'`).
- `exists` — объект уже есть в базе (при `existing: 'error'`); в первой заливке — id совпал со строкой системного класса.
- `deleted` — объект с этим id жил раньше и удалён (при `existing: 'error'`; `existing: 'update'` создаст его заново).
- `target_not_found` — цель ссылки или владелец `$owner` не найдены; с `as` — ещё цель не видна пользователю или его аккаунт не найден или отключён.
- `acl_denied` — с `as`: у пользователя нет права записи (WRITE) на класс, или строку запрещает условие прав.
- `tenant_denied` — арендатор не найден или отключён; строки `Account` — не в арендаторе System; с `as` — у пользователя нет членства в арендаторе.
- `not_empty` — `initial: true`, а в схеме уже есть данные.
