# Документы с аудитом — проверка в браузере (chrome-devtools-mcp)

Стенд: `docker compose -f services/compose.yaml up --build`, сервис — http://127.0.0.1:8084. Демо с нуля — `FRESH=1`
в `environment` сервиса `documents` в `services/compose.yaml`. Проверка — на свежем стенде: `docker compose -f
services/compose.yaml down -v`, затем `up --build` (том базы один на все сервисы — прореживание и правки прошлых прогонов
меняют число версий в шагах 11–15).
Проверка идёт автономно, через chrome-devtools-mcp: логины, пароли и данные документа вводятся в поля формы.
Простой сервиса дольше срока сессии (шаг 12) — без ожидания: в psql базы стенда
(`docker compose -f services/compose.yaml exec -T pg psql -U postgres -d letopis`) выполнить
`update "v2.documents".secret set expires_at = clock_timestamp() - interval '1 second' where kind = 'SESSION' and not (meta ? 'methods') and account = (select account from "v2.documents".secret where kind = 'PASSWORD' and ident = 'head@pravo.ru')`
— истекают сессии `createTenant` руководителя; веб-сессии входа (у них есть `methods`) не трогаются.

«Подписать» карточка могла закрыться с «Документ не найден» — сигнал SSE опережал ответ действия, и карточка

подпись «Контрагент» не была связана с полем, у полей «Новый номер», «Версия до», «Версия после» не было id (замечания
