# Кошелёк и биллинг — проверка в браузере (chrome-devtools-mcp)

Стенд — база, сайт документации и сервисы-примеры: `docker compose -f services/compose.yaml up --build`.
Сервис — http://127.0.0.1:8082.
Проверка идёт без участия человека, через chrome-devtools-mcp. Логин, пароль и данные тестовой карты вводятся в поля
формы.

Интерфейс — React и блоки shadcnblocks (`web/`), сервер — JSON API.

Прогон 31.10.2026, стенд `services/compose.yaml` (сервис на 8082, база 15440), Chrome

разошлись примерно на 0,4 с); 19 (чужая транзакция — два сеанса администратора скриптом; предупреждение `55P03`,
`rebuild({ tenant })`); 21 (в консоли только 401, 422, 504 и 409; ответов 5xx нет, кроме намеренного 504). Найдено и
исправлено: подпись флажка «без порядка блокировок» обещала `40P01` второй вкладке, а прерывается блок той, что начала
ждать раньше, — теперь «PostgreSQL прервёт один из двух блоков» (`web/src/App.tsx`); время «Под капотом» было в UTC
сервера — теперь в поясе браузера (общий код `services/shared/`). Ожидаемое шага 16 поправлено: другая вкладка ждёт
меньше 1000 мс — `deadlock_timeout` минус разница между нажатиями.
