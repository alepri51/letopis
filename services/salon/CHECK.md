# Салон записи — проверка в браузере (chrome-devtools-mcp)

Стенд поднимает `docker compose -f services/compose.yaml up --build`, салон открывается на http://127.0.0.1:8081.
Проверка — на свежем стенде: `docker compose -f services/compose.yaml down -v`, затем `up --build` (том базы один на все
сервисы — данные прошлых прогонов меняют ожидаемое).
Проверка идёт без участия человека, через chrome-devtools-mcp. Логины и пароли вводятся в поля формы.
Простой сервиса дольше срока сессии (шаг 16) — без ожидания: в psql базы стенда
(`docker compose -f services/compose.yaml exec -T pg psql -U postgres -d letopis`) выполнить
`update "v2.salon".secret set expires_at = clock_timestamp() - interval '1 second' where kind = 'SESSION' and not (meta ? 'methods') and account = (select account from "v2.salon".secret where kind = 'PASSWORD' and ident = 'admin@lokony.ru')`
— истекают сессии `createTenant` управляющей; веб-сессии входа (у них есть `methods`) не трогаются.

Интерфейс — React и shadcn/ui (`web/`), сервер — JSON API.

Прогон 03.11.2026 на letopis 2.0.0-alpha.0 (перенос — новая бронь и удаление прежней одной транзакцией, история — без
`follow`), стенд `services/compose.yaml` пересоздан с нуля (сервис на 8081, база 15440), Chrome (chrome-devtools-mcp, две
вкладки одного контекста): шаги 1–19 с вводом логинов, паролей, имени и телефона клиента, цен и списка прайса; шаги 6 и
8 и возврат надгробия переноса (409 «бронь не отменена, а перенесена…») — запросами со страницы; шаг 9 — в истории
перенесённой брони одна версия нового id (`create` 17:00, «перенос брони»), шаг 10 — в «Отменённые» попала только
отменённая бронь, надгробие переноса 15:00 — нет; шаг 16 — сессии `createTenant` истекли в базе, загрузка прайса
прошла. В консоли — только намеренные 401, 409 и 422. Сценарий `node scenario.mjs` — 27 из 27.

Прогон 31.10.2026, стенд `services/compose.yaml` (сервис на 8081, база 15440), Chrome
(chrome-devtools-mcp: инструменты MCP с явным pageId — CLI 1.4.0 не адресует страницы по pageId, а браузером
параллельно работали проверки других сервисов; две вкладки в своих изолированных контекстах, вход в каждой), с вводом

letopis: exists: …») — теперь время в поясе браузера, код один раз. Ожидаемое шага 18 поправлено: намеренные отказы
шагов 1, 6, 8 и 15 Chrome пишет в консоль.
